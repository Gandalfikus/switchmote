Switchmode

This is a first for me on github so be kind or leave. Yes this is all vibe coded and I have no real experience coding since I’m a hardware guy.

This is a somewhat stable build with some features already build in.
Features so far:

Gyro mapping as a Left Joystick from a Controller (this is for games Like Mario Kart and others)
Shake Detection as a button mapping for jumping (Mapped to right shoulder button for MK8)
Renaming Button Inputs but that is not fully fledged yet
Debug for Button Presses, Sensors and IR. (couldn’t utelize the IR data so far yet)
Added a Dark Mode for common sense and myself
Logging Data for Connection issues with Wiimotes
Current Build is in german and english but future builds will have a language setting
Debug Menu lets the user change the Threshold for shake sensitivity and calibrate the Wiimote on flat surfaces for use with the "joystick" function
Battery Percent indicator
A check if the Wiimote is in the upright or sideways position and rotates the D-Pad in turn 90 Degrees.
Detection for Nunchuk (not fully build yet)
